# 素材クレジットメーカー

配信や動画で使った素材(BOOTH の素材など)を登録しておくと、概要欄に貼る権利表記をまとめて作れるツールです。
ブラウザだけで動きます。登録した内容はサーバーに送られず、使っているブラウザの中にだけ保存されます。

**公開 URL: <https://tsuzuri-naoto.github.io/sozai-credit/>**

## できること

- 素材ごとに、区分(BGM・効果音・背景など)・素材名・ショップや作者の名前・リンクを登録できます。素材名のほかは空でもかまいません。
  - リンクには URL のほか、X の `@名前` も入れられます。
  - BOOTH の商品 URL は、末尾の `?utm_source=...` や `/` を落として短く整えます。
- 素材ごとに「表記が要るか(必須・任意・不要・未確認)」を記録できます。使い回すときに、配布元の規約を毎回見に行かずに済みます。
- 配布元が書き方を決めている素材は、その文をそのまま登録できます(YouTube オーディオライブラリの表記文など)。
- 一度登録した素材は、配信ごとに「今回使う」に印を付けるだけで使い回せます。
- 書式を 4 種類から選んで、権利表記をコピーできます。
  - **標準**: 素材ごとに「区分: 素材名 / ショップ名」とリンクを並べる
  - **1 行**: 素材ごとに 1 行にまとめる
  - **ショップごと**: ショップ名の下に素材をまとめる
  - **区分ごと**: BGM・背景などの区分の下に素材をまとめる
- ショップや作者の名前に「様」を付けるかを選べます(最初は付けません)。
- 文字数を表示します。YouTube の概要欄の上限(5000 文字)を超えると警告します。
  YouTube の概要欄に使えない `<` `>` が入っているときも警告します。
- 登録内容を JSON ファイルに書き出して、別のブラウザや別の端末で読み込めます。

## 使い方

1. 公開 URL を開きます。
2. 「素材を登録」に素材名などを入れて「追加」を押します。配布元の規約を見て「表記が要るか」も選んでおくと、次から迷いません。
3. 「登録した素材」で、今回の配信で使う素材に「今回使う」の印を付けます。
4. 書式を選び、「コピー」を押します。
5. YouTube Studio などの概要欄に貼り付けます。

### 登録内容の保存について

- 登録内容は、開いたブラウザに自動で保存されます。次に開いたときもそのまま残っています。
- ブラウザの閲覧データを消すと、登録内容も消えます。残しておきたいときは「書き出し」で JSON ファイルにしておいてください。
- 「読み込み」をすると、今の登録内容は読み込んだファイルの内容に**置き換わります**(実行前に確認が出ます)。
- 前の版で書き出したファイルも読み込めます。前の版の出力に合わせて、「様」を付ける設定で読み込みます。

### 注意

- 商品ページの中身は読みに行きません。素材名とショップ名は手で入れてください。
- 権利表記の書き方は素材ごとの利用規約に従ってください。このツールの書式が、すべての素材の規約を満たすとは限りません。

## 開発

Node.js のバージョンは `.node-version` を見てください。

```bash
npm ci
npx playwright install chromium   # 初回だけ
npm run dev                       # 開発用サーバー
npm run typecheck && npx vitest run && npx playwright test   # 型・単体テスト・ブラウザテスト
npm run build                     # dist/ に書き出す
```

`main` ブランチに push すると、`.github/workflows/pages.yml` が GitHub Pages に公開します。
